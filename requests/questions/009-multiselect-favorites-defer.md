# Request 009 questions

Planning only. No application code has been changed.

## Proposed defaults
1. **Multi-select filters:** select several values per categorical filter. Selected values within the same category match with OR; different filter categories combine with AND.
2. **Practice defer:** record a persistent deferred marker, skip the question for the rest of the current practice session, and do not record a correct/incorrect attempt or change mastery.
3. **Exam defer:** record the deferred marker but do not skip or advance. Keep the current question displayed so it can still be answered; ordinary exam navigation remains unchanged.
4. **Favourite during practice:** toggle the existing profile-local favourite state from the question screen, including after the answer is revealed. This must not change the answer or score.

## Approval
Please approve the plan and these defaults, or specify changes before implementation.
