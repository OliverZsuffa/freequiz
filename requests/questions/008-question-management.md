# Request 008: Open questions

No blocking questions remain. The defaults below were confirmed by Oliver.

1. **Profile deletion:** Permanently delete the selected profile's own data after explicit confirmation. Protect the active and final profile from leaving the app unusable.
2. **Bulk selection:** “Select all matching” covers all filtered results across every page, distinct from selecting visible results.
3. **Bulk editing:** Support all sensible, safe bulk operations, not only tags and section assignment. Do not bulk-edit the question prompt/title. Keep question content, stable IDs, provenance, and historical import snapshots protected from bulk changes.
4. **Import identity:** Track both original source/file identity and the individual import operation when available, distinguishing repeated imports of the same file.
5. **Question type:** Filtering uses answer mode: single, exactly-n, and select-all.
6. **Nested sections:** Parent section filters include descendants by default, with an explicit section-only option. Section assignment targets one specific section.
7. **Undo:** Add undo for bulk tag changes and section moves if reliable with the current persistence design.

The plan is ready for review. Explicit approval is still required before implementation begins.
